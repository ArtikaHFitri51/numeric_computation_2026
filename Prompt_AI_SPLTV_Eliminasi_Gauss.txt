TUGAS KOMPUTASI NUMERIK
SPLTV METODE ELIMINASI GAUSS

A. PROMPT TEKNIS

1. TAHAP PENYUSUNAN MODEL MATEMATIKA
[Buatkan model matematika berdasarkan studi kasus Sistem Persamaan Linear Tiga Variabel (SPLTV). Tentukan variabel yang digunakan, susun persamaan linear dari studi kasus, dan bentuk matriks augmented yang akan digunakan dalam penyelesaian.]

2. TAHAP PEMBUATAN ALGORITMA
[Buatkan algoritma penyelesaian Sistem Persamaan Linear Tiga Variabel menggunakan metode Eliminasi Gauss. Susun langkah-langkah algoritma secara berurutan sebelum diterapkan ke dalam program Python.]

3. TAHAP PEMBUATAN KODE PYTHON
[Buatkan program Python untuk menyelesaikan SPLTV menggunakan metode Eliminasi Gauss di Google Colab berdasarkan algoritma yang telah dibuat. Program harus dapat menerima input koefisien dari pengguna, melakukan Eliminasi Gauss, menjalankan substitusi mundur dan menampilkan hasil nilai X, Y, dan Z.]

4. TAHAP PENJELASAN KODE PROGRAM
[Jelaskan fungsi setiap bagian kode Python yang digunakan dalam program penyelesaian SPLTV metode Eliminasi Gauss. Gunakan bahasa sederhana agar mudah dipahami dan dapat dimasukkan ke dalam repository GitHub.]

5. TAHAP PENGUJIAN PROGRAM
[Lakukan pengujian terhadap program penyelesaian SPLTV menggunakan data yang telah ditentukan. Tampilkan input yang digunakan dan hasil keluaran program untuk memastikan program berjalan dengan benar.]

6. ANALISIS HASIL PERCOBAAN 
[Analisis hasil pengujian program dan bandingkan dengan hasil perhitungan matematis secara manual. Jelaskan apakah nilai X, Y, dan Z yang diperoleh sudah sesuai dengan penyelesaian SPLTV.]

B. PROMPT DOKUMENTASI & PRESENTASI 

1. TAHAP PENYUSUNAN MATERI PPT
[Buatkan materi PowerPoint untuk presentasi tugas Komputasi Numerik mengenai penyelesaian SPLTV menggunakan metode Eliminasi Gauss. Susun materi mulai dari studi kasus, model matematika, matriks augmented, proses eliminasi Gauss, substitusi mundur, implementasi program Python, pengujian program, hingga kesimpulan.]

2. PENYESUAIAN MATERI PRESENTASI 
[Perbaiki bagian penyelesaian matematika pada PPT. Jangan langsung menampilkan hasil perkalian tanpa menjelaskan prosesnya. Tuliskan cara perkalian setiap elemen baris secara terperinci dan tampilkan proses pengurangan secara vertikal seperti pengerjaan matematika biasa agar mudah dipahami orang lain.]

C. KETERANGAN 

Prompt pada bagian teknis digunakan untuk menyusun model matematika, membuat algoritma, mengembangkan program Python, memahami kode, serta melakukan pengujian dan analisis hasil percobaan.

Sementara itu, prompt pada bagian dokumentasi dan presentasi digunakan untuk menyusun materi PowerPoint dan menyesuaikan penjelasan agar mudah dipahami.
