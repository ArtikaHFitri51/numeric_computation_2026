A. PROMPT TEKNIS

1. TAHAP PENYUSUNAN MODEL MATEMATIKA
[Buatkan model matematika berdasarkan studi kasus Sistem Persamaan Linear Tiga Variabel (SPLTV). Tentukan variabel yang digunakan, susun persamaan linear dari studi kasus, dan bentuk matriks augmented yang akan digunakan dalam penyelesaian.]

2. TAHAP PEMBUATAN ALGORITMA
[Buatkan algoritma penyelesaian Sistem Persamaan Linear Tiga Variabel menggunakan metode Eliminasi Gauss. Susun langkah-langkah algoritma secara berurutan sebelum diterapkan ke dalam program Python.]

3. TAHAP PEMBUATAN PROGRAM PYTHON
Referensi prompt:
[Membantu membuat program Python untuk menyelesaikan SPLTV menggunakan metode Eliminasi Gauss di Google Colab berdasarkan algoritma yang telah dibuat.

Permintaan lanjutan:
- Membantu memperbaiki kesalahan pada program.
- Membantu memperbaiki proses eliminasi Gauss.
- Membantu memperbaiki proses substitusi mundur.
- Memastikan nilai X, Y, dan Z muncul semuanya.
- Membuat tampilan hasil program lebih sederhana dan mudah dipahami.]

4. TAHAP PENJELASAN KODE PROGRAM
Referensi prompt:
[Membantu memberikan penjelasan pada kode Python yang digunakan untuk menyelesaikan SPLTV metode Eliminasi Gauss agar dapat dimasukkan ke GitHub.

Permintaan lanjutan:
Menjelaskan fungsi bagian-bagian kode dan membantu menyusun penjelasan agar mudah dipahami.]

5. TAHAP PENGUJIAN PROGRAM & HASIL PERCOBAAN 
Referensi prompt:
[Membantu melakukan pengujian program SPLTV metode Eliminasi Gauss dan menjelaskan hasil percobaan.

Data pengujian:
2 1 2 170
1 2 1 120
3 1 1 160

Hasil yang diharapkan:
x = 31.6667
y = 23.3333
z = 41.6667]

Referensi prompt:
[Membantu menyusun materi penyelesaian SPLTV metode Eliminasi Gauss untuk dimasukkan ke PowerPoint.

Permintaan lanjutan:
- Menjelaskan proses penyelesaian matematis.
- Menampilkan proses eliminasi Gauss.
- Menampilkan proses substitusi mundur.
- Menjelaskan hasil perhitungan.
- Menyesuaikan isi presentasi dengan hasil program.]
